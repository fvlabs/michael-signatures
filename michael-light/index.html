Slashdev email signatures

Email-safe: table markup with inline styles, real clickable tel: / mailto: / profile links, and every animation baked into a looping GIF (email clients can’t run CSS, but they all play GIFs).

To install: find your name below and copy everything between its SIGNATURE comments into Gmail → Settings → Signature. Image URLs are already public, so it works as-is.

Gmail mobile dark mode inverts this card and leaves the images light. See the dark-mode test page for what each possible fix actually does.
